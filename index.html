FAQ

Common questions

Does my IT team need to do anything?

No. The extension installs from the Chrome Web Store like any other browser extension. No server changes, no API configuration, no IFS customisation required.

Which version of IFS does it support?

IFS Cloud using IFS Aurena. The extension uses the standard IFS OData API available on all IFS Cloud installations. It is not affiliated with or endorsed by IFS AB.

Is my IFS data secure?

Yes. The extension reads data using your existing IFS browser session — the same way IFS Aurena itself works. No credentials are stored or transmitted to any third party.

How does the 7-day trial work?

Enter your card at sign-up. You get full access for 7 days. On day 8 your card is automatically charged $299 for a full year. Cancel any time before day 8 and you pay nothing.

Can I use it on multiple computers?

Yes. One licence key works on any computer you install the extension on. Install it on your laptop and desktop with the same key.
