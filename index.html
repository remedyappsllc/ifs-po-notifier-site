Does my IT team need to do anything?

No. Both extensions install from the Chrome Web Store like any other browser extension. No server changes, no API configuration, no IFS customisation required.

Which version of IFS do they support?

IFS Cloud using IFS Aurena. Both extensions use the standard IFS OData API available on all IFS Cloud installations.

Is my IFS data secure?

Yes. Both extensions use your existing IFS browser session — the same way IFS Aurena itself works. No credentials are stored or transmitted to any third party.

How does Smart Notes pricing work?

Smart Notes is priced per company, not per user. One $599/yr licence covers everyone at your company. All users who install the extension see the same shared notes.

Can I use the extensions on multiple computers?

Yes. One licence key works on any computer. Install on your laptop and desktop with the same key.
